
#Common UDP Port Numbers


port	protocol	description

53	DNS	Domain Name System (name resolution)
67 / 68	DHCP	Dynamic Host Configuration Protocol (server/client)
69	TFTP	Trivial File Transfer Protocol
123	NTP	Network Time Protocol (clock synchronization)
137 / 138	NetBIOS	NetBIOS Name Service and Datagram Service
161 / 162	SNMP	Simple Network Management Protocol
443     QUIC (HTTP/3)
500	ISAKMP / IKE	Internet Key Exchange (IPsec VPN setup)
1194	OpenVPN	OpenVPN secure tunnel protocol
1725	Steam	Valve Steam client local networking
5060    SIP (VOIP)
