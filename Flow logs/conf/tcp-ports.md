
# Common Well-Known TCP Ports (0 – 1023)

port	service	    description
20 / 21	FTP	File Transfer Protocol (Data / Control)
22	SSH	Secure Shell (remote command-line access)
23	Telnet	Unencrypted text communications
25	SMTP	Simple Mail Transfer Protocol (email routing)
53	DNS	Domain Name System (also uses UDP)
67 / 68	DHCP	Dynamic Host Configuration Protocol
69	TFTP	Trivial File Transfer Protocol
80	HTTP	Hypertext Transfer Protocol (unencrypted web traffic)
88	Kerberos	Network authentication protocol
110	POP3	Post Office Protocol version 3 (retrieving email)
119	NNTP	Network News Transfer Protocol
123	NTP	Network Time Protocol
135	RPC	Microsoft Remote Procedure Call
139	NetBIOS	NetBIOS Session Service
143	IMAP	Internet Message Access Protocol
161 / 162	SNMP	Simple Network Management Protocol
179	BGP	Border Gateway Protocol
389	LDAP	Lightweight Directory Access Protocol
443	HTTPS	HTTP Secure (encrypted web traffic)
445	SMB	Server Message Block (file sharing)
514	Syslog	Computer message logging
636	LDAPS	LDAP over TLS/SSL
